## Conventions

- One folder per platform or event; writeups are named `<event>-<challenge>-<date>.md`.
- Writeups record the method and the evidence. Flags for completed public challenges are kept in RESULTS.md and the writeups.
- Real credentials, passwords, tokens, and personal data are never written here; where a step involved them, they are only referenced, never printed.
