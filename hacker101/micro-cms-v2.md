# Micro-CMS v2 — 調査メモ

- 実施日: 2026-10-29
- 対象: [Hacker101 CTF の Micro-CMS v2](https://ctf.hacker101.com/ctf)
- 状態: 実験環境は起動済み。フラグ 0/3
- 課題インスタンスのホスト名やフラグ値は公開しない

## 確認したこと

1. v1 の実験環境が起動中は、v2 の Start リンクが無効だった。v1 を終了すると v2 を起動できた。
2. v2 のトップページには「Micro-CMS Changelog」と「Markdown Test」、新規ページ作成リンクがある。
3. Changelog には、v1 の欠陥を修正し、ユーザー認証を追加したと書かれている。既定ではページの追加・編集に管理者権限が必要。
4. 「Edit this page」を開くと、ユーザー名とパスワードのログイン画面へ転送された。

## 停止した検証

ログインフォームへの SQL インジェクションを使った認証回避の入力・送信は、自動承認レビューで拒否された。理由は、CTF 全体の解答依頼だけではこの具体的な認証回避手法への承認が足りないというもの。拒否後は別経路を使わず停止した。実行結果やフラグは得ていない。

次にこの方法を検証するには、Hacker101 CTF の Micro-CMS v2 のログインフォームで SQL インジェクションによる認証回避を試してよいという、本人の明示的な承認が必要。
